About This System

This is a Cloud Computing coursework project from Makerere University, demonstrating how machine learning can be deployed on cloud infrastructure to deliver accessible health screening at scale.

The prediction engine uses a Soft Voting Ensemble:

Logistic Regression (active — client-side) Random Forest (ensemble extension) Neural Network MLP (ensemble extension)

Dataset

Trained on the Pima Indians Diabetes Dataset (UCI ML Repository), 768 records, 8 clinical features expanded to 15 via feature engineering (interaction terms). The dataset is limited to female patients aged ≥ 21.

Limitations

  • Trained on a single demographic (Pima women, age ≥ 21)
  • 8 input features — clinical assessments use many more
  • ~72% accuracy — not clinically sufficient as a standalone tool
  • Not a substitute for formal medical screening

Cloud Architecture (IaaS / PaaS / SaaS)

This system demonstrates all three NIST cloud service models:

SaaS This web app — served via GitHub Pages CDN. Patients access it from any browser with no installation.
PaaS API server (FastAPI) deployable on Render / Google App Engine for RF + MLP ensemble extensions. Managed PostgreSQL (Neon) for prediction history storage.
IaaS Cloud VM (GCP Compute Engine / AWS EC2) hosting the ML inference container. Object storage bucket holding model .pkl files and training data.

Why GitHub Pages?

Because the Logistic Regression model is mathematically a simple dot product + sigmoid function, the full trained model (coefficients + scaler) is embedded directly into this JavaScript file. This means:

  • Zero cold starts (unlike Render free tier which sleeps after 15 min)
  • Globally distributed via GitHub's CDN
  • No API keys, no authentication overhead
  • 100% free, indefinitely

For the full ensemble (RF + MLP), a Cloudflare Worker (free: 100k requests/day, 0ms cold start) is recommended over Render as the API backend.
