About This System

Cloud Computing coursework project from Makerere University demonstrating how ML can be deployed on cloud infrastructure to deliver scalable, browser-accessible health screening.

Ensemble Architecture

Logistic Regression — Active (client-side)
Random Forest — Planned
Neural Network (MLP) — Planned

Dataset

Pima Indians Diabetes Dataset (UCI ML Repository) — 768 female patient records, 8 clinical features expanded to 15 via engineered interaction terms. Binary outcome: diabetic / non-diabetic.

Limitations

  • Single demographic (Pima women, age ≥ 21)
  • ~72% LR accuracy — not clinically sufficient alone
  • Not a substitute for formal medical assessment

Cloud Service Models (NIST)

SaaS

This web app — served via GitHub Pages CDN globally. Zero installation. Any browser, any device, anywhere in the world.

PaaS

FastAPI server for RF + MLP ensemble — Cloudflare Workers (0ms cold start, 100k req/day free) or Render. Managed PostgreSQL via Neon for prediction history.

IaaS

Cloud VM (GCP Compute Engine / AWS EC2) hosting the ML container. Object storage bucket (S3/GCS) for .pkl model files and training data.

Why GitHub Pages?

Logistic Regression is sigmoid(X·w + b) — pure arithmetic. The trained model coefficients are embedded directly in JavaScript: zero cold starts, globally cached, 100% free.

Cloudflare Workers vs Render

For the RF + MLP backend: Cloudflare Workers give 0ms cold start and 100k requests/day on the free tier. Render's free tier sleeps after 15 min, causing ~30s cold start delays.
